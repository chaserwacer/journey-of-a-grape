# Journey of a Grape

This project is a single interactive webpage in [v2.html](v2.html).  
You do not need to install anything to run it.

## How to Open It (Simple)

1. Open this project folder on your computer.
2. Double-click [v2.html](v2.html).
3. Your browser will open the experience.
4. Choose a grape, then click **Begin Your Journey**.

## If Double-Click Does Not Work

1. Open Chrome, Edge, or Firefox.
2. Drag [v2.html](v2.html) into the browser window.

## Keep These Files Together

- Keep [v2.html](v2.html) in the same folder as [assets](assets/).
- The page loads images from [assets](assets/), so moving files can break visuals.

## Controls

- Keyboard:
  - Arrow keys or W A S D to move
  - E or Space to interact
- Phone/tablet:
  - Use the on-screen controls

## Troubleshooting

- Images missing:
  - Confirm [assets](assets/) is next to [v2.html](v2.html).
- Fonts look different:
  - Check internet connection (Google Fonts are loaded online).
- Page seems unresponsive:
  - Try Chrome or Edge.
